# Карта репозитория: юзерскрипт

> [!NOTE]
> Репозиторий `foulnike/Animori-Script` — только юзерскрипт. Приложение живёт
> в `foulnike/AniMori-AniList-Toolkit`, версия для приставки — в
> `foulnike/Animori-TV`. Общей кодовой базы между ними нет: до версии 1.9
> скрипт и настольная оболочка собирались из одних исходников, 24.08.2026 их
> разделили, а 20.09.2026 разъехались по репозиториям.

## Ветки

| Ветка | Состояние |
| --- | --- |
| `main` | Единственная и рабочая: здесь код, словарь и выпуски |

Ветка по умолчанию, из неё же собирается выпуск. Иных веток репозиторий не
держит: расписание `.github/` работает только из ветки по умолчанию, и вторая
ветка означала бы вторую копию конвейера.

## Что лежит здесь

```
src/main.ts            порядок запуска: один шаг — одна возможность
src/core/              настройки, БД, словарь, жизненный цикл, сеть
src/api/               AniList, Шикимори, anime365, AnimeThemes, словарь
src/features/          возможности: интерфейс, переводчик, поиск,
                       медиа-виджеты, сканер, перенос списка
src/bridge/index.ts    единственная дверь к GM_*-функциям
src/utils/             DOM, журнал, сверка названий, монтирование Vue
src/style.scss         все стили скрипта одним файлом
dictionary.json        словарь перевода интерфейса, раздаётся по прямому адресу
```

Сборка даёт два файла: `dist/animori.user.js` (сам скрипт, около 610 КБ) и `dist/animori.meta.js` (только шапка, для проверки обновлений).

## Чего здесь нет и быть не должно

| Чего нет | Где это |
| --- | --- |
| `src-tauri/`, Rust, оболочка окна | `AniMori-AniList-Toolkit` и `Animori-TV` |
| Десктопная реализация моста, вызовы `@tauri-apps/*` | Там же |
| Блокировщик рекламы | Нигде: в браузере рекламу режет расширение пользователя |
| Прокси-туннель и его настройки | Там же |
| Архив документации 2.x | Ветка `main` старого репозитория и уже вышедшие релизы |

Платформа здесь одна, и в коде о ней нигде не спрашивают: ни поля `platform` у моста, ни подстановки времени сборки больше нет. Сам мост — один файл `src/bridge/index.ts` без интерфейсов и псевдопутей под вторую реализацию. Появилась ветвь по платформе — вместе с ней сюда приехал чужой код.

## Выпуски

| Тег | Что собирает | Куда попадает |
| --- | --- | --- |
| `script-*` | Юзерскрипт | Релиз этого репозитория с `animori.user.js` |

Теги `app-*` и `v*` к этому репозиторию не относятся: `app-*` собирает
приложение в `AniMori-AniList-Toolkit`, а `v*` — история гибрида 2.x, чьи
релизы остались там же.

Порядок выпуска: поднять `version` в `package.json`, переименовать блок `## [Не выпущено]` в `CHANGELOG.md`, поставить тег `script-<версия>`. Сборочный поток — `.github/workflows/release.yml`, срабатывает только на `script-*`.

На Greasy Fork файл выкладывается руками — [скрипт 572948](https://greasyfork.org/ru/scripts/572948-animori-anilist-toolkit). Автообновления из релиза GitHub у нас нет, поэтому пропущенная выкладка означает, что пользователи остались на прежней версии.

## Словарь

`dictionary.json` (около 185 КБ) лежит в корне этого репозитория. Скрипт качает его по адресу из `DICT_URL`:

```
https://raw.githubusercontent.com/foulnike/Animori-Script/main/dictionary.json
```

Правка словаря доезжает до пользователей без нового выпуска скрипта: файл
забирается с сети при каждом запуске. Пополняют его через шаблоны обращений
`dictionary-bulk.yml` и `translation.yml` с метой `dictionary`.

**Копия в старом репозитории оставлена замороженной намеренно.** По адресу
`raw.githubusercontent.com/foulnike/AniMori-AniList-Toolkit/main/dictionary.json`
ходят все установленные копии прежних версий; они перейдут на новый адрес
только вместе с новым выпуском скрипта. Удалённый файл дал бы им 404, и
перевод интерфейса отвалился бы молча.
